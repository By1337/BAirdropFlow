# YAML-редактор команд

Команды ноды редактируются целиком как `on_run` в EventDSL, включая `create`,
`remove`, `call` и `destroy`. Граф строит связи из этого YAML. Команды спавнера
используют тот же редактор. `if`, `if-all`, `if-one`, `oneOf`, `weights`,
`all_players`, `nearby-N`, неизвестные команды и многострочные сообщения
сохраняют исходную YAML-структуру без преобразования в визуальные карточки.

Подсветка — в стиле Darcula. Отступ — два пробела; Enter после ключа создаёт
вложенный уровень, учитывая `- key:`. Есть номера строк, сворачивание блоков,
поиск, история изменений и кнопка разворачивания в большое окно.
У размеров нод команд и заметок нет прежнего верхнего ограничения. Поля
спавнера можно растягивать по высоте.

| Бинд | Действие |
| --- | --- |
| Ctrl+D | Дублировать строку |
| Ctrl+Y | Удалить строку |
| Ctrl+/ | Комментарий |
| Ctrl+Z / Ctrl+Shift+Z | Отмена / повтор |
| Shift+Alt+↑ / ↓ или Ctrl+Shift+↑ / ↓ | Переместить строки |
| Ctrl+Alt+L | Выравнивание отступов YAML |
| Ctrl+F | Поиск и замена |
| Ctrl+Space | Подсказки |
| Tab / Shift+Tab | Отступ / убрать отступ |
| Ctrl+Enter | Вставить новую строку |
| Ctrl+S | Проверить YAML и сохранить сценарий |

На macOS используются ⌘-бинды; вызов подсказок остаётся Ctrl+Space.
Подсказки включают команды EventDSL/BAirdropFlow, шаблоны управляющих структур,
сигнатуры и примеры аргументов, ID нод и плейсхолдеры args. Для вложенного
`nearby: 10 [sound] ...` распознаётся последняя команда. Названия звуков и
эффектов предлагаются из небольшого набора примеров; другие значения можно
вводить свободно. `make` и `set_value` предлагаются только в спавнере.

При уходе из поля и при сохранении YAML проверяет существующий серверный
парсер. Ошибка показывается под редактором, текст остаётся доступным для
исправления. Перемещение/растягивание нод сохраняет редактор и его историю.
CodeMirror собирается локально в `web/dist/bairdropflow/app.js`, без CDN.

Сборка: `npm --prefix web ci`, затем `npm --prefix web run build`.
